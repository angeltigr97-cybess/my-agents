# my-agents

Коллекция AI-агентов: от небольших помощников для повседневных задач до более сложных многошаговых сценариев автоматизации.

> ⚠️ Проект находится на начальной стадии. Структура и состав агентов будут дополняться.

## О проекте

Цель репозитория — собрать в одном месте собственных агентов, их конфигурации, промпты и вспомогательные инструменты, чтобы:

- быстро запускать и переиспользовать готовых агентов;
- хранить промпты и настройки под версионным контролем;
- экспериментировать с новыми идеями и сравнивать подходы.

## Структура репозитория

Планируемая структура (будет уточняться по мере развития):

```
my-agents/
├── agents/        # Определения агентов (промпты, конфигурации, код)
├── tools/         # Общие инструменты, которые используют агенты
├── examples/      # Примеры запуска и сценарии использования
├── docs/          # Дополнительная документация
└── README.md
```

## Быстрый старт

```bash
git clone https://github.com/angeltigr97-cybess/my-agents.git
cd my-agents
```

Инструкции по установке зависимостей и запуску конкретных агентов будут добавлены вместе с самими агентами.

## Как добавить нового агента

1. Создайте папку `agents/<имя-агента>/`.
2. Добавьте описание агента (`README.md`) — что он делает, какие входные данные ожидает и что возвращает.
3. Положите промпт/конфигурацию и код агента.
4. Добавьте агента в таблицу выше.
