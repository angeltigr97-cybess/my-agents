# my-agents

Коллекция AI-агентов: промпты, конфигурации и код. Язык документации — русский.

## Структура

- `agents/<имя-агента>/` — один агент на папку: `README.md` (что делает, вход, выход), промпт/конфиг, код.
- `tools/` — общие инструменты, которые используют несколько агентов.
- `examples/` — примеры запуска и сценарии.
- `docs/` — дополнительная документация.
- `.claude/` — настройки Claude Code для этого репозитория (скиллы, сабагенты, разрешения).

## Правила

- Новый агент создаётся через скилл `/new-agent` и обязательно добавляется в таблицу «Агенты» в корневом `README.md`.
- Имена папок агентов — `kebab-case`.
- Не коммитить секреты (API-ключи, токены). Ключи — только через переменные окружения; пример — в `.env.example`.
- Личные настройки Claude Code — в `.claude/settings.local.json` (он в `.gitignore`).

## Проверка изменений

Перед коммитом попросите сабагента `agent-reviewer` проверить нового или изменённого агента.
